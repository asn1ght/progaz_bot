# PLAN.md

# План разработки ProGaz Telegram Bot

## Общая информация

Проект разрабатывается поэтапно.

Цель:

Создать рабочий MVP Telegram-бота для автоматизации:

- учета объектов;
- планирования выездов инженеров;
- контроля проверок;
- учета счетов;
- контроля оплат.

---
